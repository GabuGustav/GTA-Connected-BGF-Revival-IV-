# 🚀 GitHub Release Setup Instructions

## 📋 Files to Upload
Copy these files from your `downloadable-files/` folder:
- `componentpeds.img.zip` (1.04 GB)
- `pedprops.img.zip` (48 MB)  
- `radar.img.zip` (1.3 MB)
- `Vehicle.img.zip` (138 MB)
- `weapons.img.zip` (5.3 MB)
- `weapons_e1.img.zip` (10.8 MB)
- `weapons_e2.img.zip` (3.7 MB)

## 🔧 Step-by-Step Instructions

### 1. Go to GitHub Releases
**URL**: https://github.com/GabuGustav/GTA-Connected-BGF-Revival-IV-/releases

### 2. Create New Release
- Click **"Create a new release"** button
- Tag version: `v1.0.0`
- Release title: `BGF Revival IV - Download Files`

### 3. Upload Files
- Click **"Choose files"** or drag & drop
- Upload all 7 ZIP files listed above
- Wait for uploads to complete (may take time for large files)

### 4. Publish
- Click **"Publish release"**
- Your files are now available for download!

## 🌐 Result
After publishing, your downloads will work from:
- Your live Netlify site
- GitHub Releases CDN
- Direct download links

## ⏱️ Upload Time
Large files may take 10-30 minutes to upload depending on your internet speed.

## 📱 Mobile Option
You can also do this from the GitHub mobile app if desktop upload is slow.
